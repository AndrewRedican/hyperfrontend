# models

Repository data models: platforms, configurations, and inference results.

[`RepositoryPlatform`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-RepositoryPlatform) plus [`KnownPlatform`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-KnownPlatform), [`PLATFORM_HOSTNAMES`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-PLATFORM_HOSTNAMES), [`isKnownPlatform`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-isKnownPlatform), and [`detectPlatformFromHostname`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-detectPlatformFromHostname) cover the supported source-code platforms (GitHub, GitLab, Bitbucket, Azure DevOps). [`RepositoryConfig`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-RepositoryConfig) (built via [`createRepositoryConfig`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-createRepositoryConfig), validated via [`isRepositoryConfig`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-isRepositoryConfig)) carries the platform, owner, repo name, and the [`CompareUrlFormatter`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-CompareUrlFormatter) that produces version-diff URLs. [`RepositoryResolution`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-RepositoryResolution) (with [`createDisabledResolution`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-createDisabledResolution), [`createExplicitResolution`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-createExplicitResolution), [`createInferredResolution`](https://www.hyperfrontend.dev/docs/libraries/versioning/repository/models/#api-createInferredResolution)) captures how a resolution was reached: explicitly configured, inferred from `package.json`, or deliberately disabled.
