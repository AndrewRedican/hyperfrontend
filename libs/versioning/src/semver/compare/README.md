# compare

Version-comparison primitives: equality, strict ordering, range satisfaction, and sort utilities.

[`compare`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-compare), [`eq`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-eq), [`lt`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-lt), [`lte`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-lte), [`gt`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-gt), [`gte`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-gte), and [`neq`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-neq) are the basic ordering operators over [`SemVer`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/models/#api-SemVer) values. `satisfies`, [`satisfiesComparator`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-satisfiesComparator), [`maxSatisfying`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-maxSatisfying), and [`minSatisfying`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-minSatisfying) answer range-membership and best-fit questions against [`Range`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/models/#api-Range) and [`Comparator`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/models/#api-Comparator) shapes. [`sort`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-sort) and [`sortDescending`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-sortDescending) produce stable orderings; [`max`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-max) and [`min`](https://www.hyperfrontend.dev/docs/libraries/versioning/semver/compare/#api-min) are the convenience reductions. Behavior is fully spec-compliant with semver precedence, including the prerelease tie-breaker rules.
