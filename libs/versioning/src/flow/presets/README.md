# presets

Pre-configured release flows for the most common monorepo and single-package release strategies.

[`createConventionalFlow`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createConventionalFlow) (plus [`createMinimalFlow`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createMinimalFlow) and [`createChangelogOnlyFlow`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createChangelogOnlyFlow)) covers single-package conventional-commit-driven releases. [`createIndependentFlow`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createIndependentFlow) and [`createBatchReleaseFlow`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createBatchReleaseFlow) cover monorepos where each package versions independently; [`createCheckDependentBumpsStep`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createCheckDependentBumpsStep) is the cascade-bump helper that powers the dependent-package check. [`createSyncedFlow`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createSyncedFlow), [`createFixedVersionFlow`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createFixedVersionFlow), [`createSyncAllPackagesStep`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createSyncAllPackagesStep), and [`createCombinedChangelogStep`](https://www.hyperfrontend.dev/docs/libraries/versioning/flow/presets/#api-createCombinedChangelogStep) cover monorepos that release all packages together at a synced version. Each preset exposes a `*_FLOW_CONFIG` constant alongside its factory so consumers can read the canonical step list before tweaking.
