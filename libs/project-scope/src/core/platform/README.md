# platform

Operating system detection and platform-specific normalization for filesystem case sensitivity and line endings.

[`detectPlatform`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-detectPlatform), [`getPlatformInfo`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-getPlatformInfo), [`isWindows`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-isWindows), [`isMac`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-isMac) and [`isLinux`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-isLinux) classify the host OS; [`isCaseSensitiveFs`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-isCaseSensitiveFs) and [`detectCaseSensitivity`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-detectCaseSensitivity) decide whether path comparisons must be case-aware, by probing the file system, since APFS and NTFS volumes can be configured either way. Line-ending helpers ([`detectLineEnding`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-detectLineEnding), [`getLineEnding`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-getLineEnding), [`normalizeLineEndings`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-normalizeLineEndings), plus [`LF`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-LF)/[`CRLF`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-CRLF) constants) let writers convert content to a consistent style before commit. [`pathsEqual`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-pathsEqual) performs platform-aware path equality, and [`getPathSeparator`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/platform/#api-getPathSeparator) returns the active separator.
