# path

Cross-platform path manipulation utilities that normalize between POSIX and native (Windows) separators.

Grouped into four concerns: joining ([`join`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-join), [`joinPosix`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-joinPosix), [`joinPath`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-joinPath)), normalization ([`normalizePath`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-normalizePath), [`normalizeToForwardSlashes`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-normalizeToForwardSlashes), [`normalizeToNative`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-normalizeToNative), trailing-slash helpers), resolution ([`resolvePath`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-resolvePath), [`resolveRealPath`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-resolveRealPath), [`resolveFromWorkspace`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-resolveFromWorkspace), [`relativePath`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-relativePath), [`offsetFromRoot`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-offsetFromRoot), [`isAbsolute`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-isAbsolute)), and segment extraction ([`getDirname`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-getDirname), [`getBasename`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-getBasename), [`getExtension`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-getExtension), [`getFileNameWithoutExtension`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-getFileNameWithoutExtension), [`parsePath`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-parsePath), [`pathSegments`](https://www.hyperfrontend.dev/docs/libraries/project-scope/core/path/#api-pathSegments)).

All functions emit forward-slash paths by default to keep downstream string comparisons portable across operating systems.
