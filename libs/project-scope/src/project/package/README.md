# package

`package.json` reading, dependency inspection, and version-check helpers.

[`readPackageJson`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-readPackageJson) and [`readPackageJsonIfExists`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-readPackageJsonIfExists) parse `package.json` into a typed [`PackageJson`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-PackageJson) shape. [`findNearestPackageJson`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-findNearestPackageJson) walks up from a starting path to locate the closest manifest. [`getDependencies`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-getDependencies), [`getDevDependencies`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-getDevDependencies), [`getPeerDependencies`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-getPeerDependencies), [`getProductionDependencies`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-getProductionDependencies), and [`getAllDependencies`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-getAllDependencies) slice the manifest into typed maps; [`hasDependency`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-hasDependency), [`hasInstalledPackage`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-hasInstalledPackage), and [`getDependencyVersion`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-getDependencyVersion) answer presence and version-range questions. [`getWorkspaces`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-getWorkspaces) / [`hasWorkspaces`](https://www.hyperfrontend.dev/docs/libraries/project-scope/project/package/#api-hasWorkspaces) surface monorepo workspace declarations from npm, Yarn, or pnpm.
