# selector

CSS-selector builder, validators, and DOM-query shortcuts that produce safer selectors than ad-hoc string concatenation.

[`CssSelector`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-CssSelector) is a fluent builder for composing selectors out of tag, id, class, and attribute parts; the validator family ([`validateCssName`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-validateCssName), [`validateStringArgument`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-validateStringArgument), [`validateIdSelector`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-validateIdSelector), [`validateClassSelector`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-validateClassSelector), [`validateAttributeSelector`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-validateAttributeSelector), [`isValidCssSelector`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-isValidCssSelector)) rejects inputs that would produce malformed or surprising selectors before they reach the DOM. The query helpers ([`select`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-select), [`selectBy`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-selectBy), [`selectByElement`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-selectByElement), [`selectAllElements`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-selectAllElements), [`selectById`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-selectById), [`selectByClass`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-selectByClass), [`selectByAttribute`](https://www.hyperfrontend.dev/docs/libraries/utils/ui/selector/#api-selectByAttribute)) wrap `querySelector` / `querySelectorAll` so callers don't have to repeat the boilerplate or remember the typed return shapes.
