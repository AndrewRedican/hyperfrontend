# security

Types and errors a security protocol implements: the per-session seal and open operations, the session, the hello exchange outcome, and the rejection codes.

[`SecuritySuite`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/security/#api-SecuritySuite) pairs a [`PacketSealer`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/#api-PacketSealer) with a [`PacketOpener`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/#api-PacketOpener). [`ProtocolSession`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/#api-ProtocolSession) (`{ protocol, role, localId, peerId }`, with [`SessionRole`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/#api-SessionRole) as `'initiator' | 'responder'`) is what a [`ProtocolProvider`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/#api-ProtocolProvider) binds a protocol instance to, and [`HelloOutcome`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/#api-HelloOutcome) (`'accepted' | 'duplicate' | 'rejected'`) is what accepting a peer's hello frame returns. [`ProtocolErrorCode`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/security/#api-ProtocolErrorCode) lists why a protocol rejects a frame or a session (`unsupported-version`, [`replayed`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/security/#api-ProtocolErrorCode), `authentication-failed`, [`malformed`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/security/#api-ProtocolErrorCode), `counter-exhausted`, `invalid-session`); [`createProtocolError`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/security/#api-createProtocolError) builds a [`ProtocolError`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/security/#api-ProtocolError) carrying one, and [`getProtocolErrorCode`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/security/#api-getProtocolErrorCode) reads the code off a drop's [`cause`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/#api-PacketDrop-prop-cause).
