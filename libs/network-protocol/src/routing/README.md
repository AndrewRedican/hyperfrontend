# routing

Packet routing primitives: subscription types and routed-packet creators that pair a packet with a topic.

[`Router`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-Router) is the function that turns the available channels and topics into [`RoutingOptions`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-RoutingOptions): [`isDynamic`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-RoutingOptions-prop-isDynamic) (whether subscriptions are fetched anew for each message or once and cached) and [`subscriptions`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-RoutingOptions-prop-subscriptions), a `WeakMap` from channel to its subscribed topics. [`RoutedPacket`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-RoutedPacket), [`RoutedWirePacket`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-RoutedWirePacket), and [`RoutedUnencryptedPacket`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-RoutedUnencryptedPacket) are the envelopes that carry a topic id beside a sealed frame or a plaintext packet; [`createRoutedWirePacket`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-createRoutedWirePacket) and [`createRoutedUnencryptedPacket`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-createRoutedUnencryptedPacket) produce them and throw for a topic id that is not a UUID v4.
