# topic

Topic registry: a store for the named topics that channels subscribe to.

[`Topic`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/topic/#api-Topic) is a name paired with a generated UUID v4 [`id`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/topic/#api-Topic-prop-id). [`TopicStore`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/topic/#api-TopicStore) holds topics with [`create`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/topic/#api-TopicStore-prop-create) (by name, ids generated), [`add`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/topic/#api-TopicStore-prop-add) (existing objects), lookups by name or id, [`list`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/topic/#api-TopicStore-prop-list), and removal by name or id. [`createTopicStore`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/topic/#api-createTopicStore) is the factory; consumers compose the store with channels and a [`Router`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/#api-Router) from [`/routing`](https://www.hyperfrontend.dev/docs/libraries/network-protocol/routing/) to drive topic-based message delivery.
