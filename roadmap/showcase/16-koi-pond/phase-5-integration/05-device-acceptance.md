## Goal

The author walks the deployed result on the physical phone that started all of this (the
S24 Ultra frame-death lane: docs-site gallery card, background excursions, return). This
is an operator checklist, not an implementation task; batch every ask into one session.

## Checklist (deployed docs-site, then the standalone pond origin)

1. **Card**: the gallery card shows one resting koi (sculling, no held chrome, surface
   depth, ripples); the fish matches the hour rotation.
2. **Expand**: one curtain, then the trio lands; the card's koi is among the three; no
   stretched card world is ever visible.
3. **Shoal panel**: add koi up to the phone's tier cap; the refusal names the tier;
   remove works per instance; duplicates of one framework are visibly the same species
   with different builds/markings.
4. **Overlay**: cones stay attached through hard turns; pearls are consumed as each
   fish swims through them; the caret slides ahead of turns; nothing is color-coded.
5. **Motion**: hard turns visibly brake; two fish meeting head-on break right around
   each other.
6. **Background/return cycles**: repeat the original kill lane (leave the tab, browse
   heavy apps, return). Contexts release on hide and rebuild staggered on return; if
   Android still kills a frame, the pond heals it (inner resurrection) and the gallery
   heals a dead pond (outer resurrection); no crash placeholder persists.
7. **Vitals**: `?vitals=1` works in both the card and the expanded instance; the boot
   line records the device tier; roster changes and any cap refusals appear in the log.
8. **Collapse**: Escape and the close control both land back in a live card.

## Exit criterion

The original failure signature (a dead frame's placeholder sitting in the scene) is
either not reproducible in a reasonable number of excursion cycles, or provably healed
within the resurrection budgets every time it occurs. Record the session's outcome in
the demo working log; if any check fails, file the evidence and loop back to the owning
sub-plan rather than patching ad hoc.
