## Scope (to elaborate)

- **Russian-doll / nested**: a hostee that is itself a host, chained — short but long enough to prove it; the gallery mounting a demo's own host makes the nesting recursive. Takes the repurposed `events` slot ([catalog.md](catalog.md) §4/§5); the gallery teaser already advertises the nested identity. The koi pond ([15](15-koi-pond.md)) delivers the _first_ live gallery → host → hostee chain; this demo proves the deeper, deliberate chain.
- **Cross-framework matrix**: framework-X host embedding framework-Y feature, across several pairs — agnosticism shown, not claimed.
- **Many:many coordination**: multiple hosts and hostees on a shared message bus.
- **Framework chess**: two framework-distinct feature apps playing each other through a host (the "chess"/"framework chess" headlines, reconciled into one demo in [catalog.md](catalog.md)).
